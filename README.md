 Interactive Solar System Simulation

An interactive and visually immersive Solar System Simulation built using HTML, CSS, and JavaScript.

This project recreates the planetary system with animated orbital motion, glowing visual effects, interactive hover animations, and informative cosmic fact panels — all directly inside the browser without using external frameworks.

The idea behind this project was to combine creativity, frontend development, smooth animations, and educational visualization into one engaging web experience.

🌍 Planet Sizing

Planet sizes are designed approximately according to their real-world proportions for a more realistic appearance.

Jupiter is the largest planet
Saturn appears slightly smaller with rings
Earth and Venus are medium-sized terrestrial planets
Mercury is the smallest visible planet

The system is visually balanced to maintain realism while still keeping the interface clean and interactive.
